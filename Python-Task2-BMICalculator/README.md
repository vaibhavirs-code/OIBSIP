# BMI Calculator
This is a simple BMI Calculator developed using Python as part of my Oasis Infobyte Python Programming Internship.

## Features
- Takes weight in kilograms
- Takes height in meters
- Calculates BMI
- Displays BMI up to 2 decimal places
- Shows BMI category
- Handles invalid input
- Rejects negative and zero values and displays error message

## BMI Categories
- Below 18.5 - Underweight
- 18.5 to 24.9 - Normal weight
- 25 to 29.9 - Overweight
- 30 and above - Obese

## How to Run
1. Open `bmi_calc.py` in VS Code.
2. Run the Python file.
3. Enter your weight and height when asked.
4. The BMI and category will be displayed.
